# Pizza Sales Analysis Dashboard

## Project Overview
This project presents an end-to-end **Pizza Sales Analysis Dashboard** developed using Power BI, with data processing and transformation performed using Python (Pandas) and SQL.  
The objective is to analyze sales performance, understand customer behavior, and generate actionable business insights to support data-driven decision-making.

---

## Business Objectives
- Identify top and bottom performing pizzas  
- Analyze sales trends by time (hour, day, month)  
- Evaluate category and size-wise performance  
- Understand customer ordering behavior  
- Provide actionable recommendations to improve sales  

---

## Tools & Technologies
- **Power BI** – Data visualization & dashboarding  
- **SQL / PostgreSQL** – Data extraction & analyzing  
- **Python (Pandas)** – Data cleaning & preprocessing  
- **CSV** – Datasets 

---

## Dataset Description
There are 4 different datasets includes transactional data with the following key fields:
- Order ID  
- Date & Time  
- Pizza Name  
- Category & Size  
- Quantity  
- Price & Revenue  

---

## Key KPIs
- Total Revenue  
- Total Orders  
- Total Quantity Sold  
- Average Order Value  
- Average Pizzas per Order  

---

## Dashboard Features

### 1. Sales Overview
- Monthly and daily order trends  
- Category and size-wise performance  
- Peak sales periods  

### 2. Product Analysis
- Top 10 pizzas by revenue and quantity  
- Bottom 10 pizzas analysis  
- Performance comparison across products  

### 3. Advanced Analysis
- **Hourly Order Trend** → Identifies peak demand hours  
- **Revenue vs Demand (Scatter Plot)** → Shows impact of pricing vs quantity  
- **Average Pizzas per Order** → Analyzes customer ordering behavior  

---

## Key Insights
- Orders peak during afternoon and evening hours  
- Revenue is driven by both customer demand and pricing strategy  
- Customers typically order 1–2 pizzas per transaction  
- Low-performing pizzas show weak demand and revenue  

---

## Business Recommendations
- Promote high-demand pizzas to maximize revenue  
- Optimize pricing strategy for better profitability  
- Use promotional offers during low-demand hours  
- Introduce combo deals to increase average order value  
- Improve or remove low-performing pizzas  

---

## Conclusion
This dashboard enables businesses to:
- Monitor sales performance effectively  
- Understand customer behavior  
- Make data-driven decisions to improve revenue and operations
